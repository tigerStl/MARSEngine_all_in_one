# MarsSpyTool 使用手册

## 1. Web 联动前置条件（Chrome / Edge 调试端口）

当 Finder 拖放到 Web 对象并希望联动 `MARS.WebAutomation` 获取页面 URL/对象树时，需先为浏览器启用 CDP 远程调试端口。

> 注意：仅使用 `--remote-debugging-port=9222` 在新版浏览器上可能被忽略。  
> 建议始终配合 `--user-data-dir` 使用独立用户目录。

## 2. 启动命令

### 2.1 Microsoft Edge

```bat
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --remote-debugging-port=9222 --user-data-dir="C:\temp\edge-cdp"
```

### 2.2 Google Chrome

```bat
"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\temp\chrome-cdp"
```

## 3. 验证端口是否生效

启动后访问以下地址：

- [http://127.0.0.1:9222/json/version](http://127.0.0.1:9222/json/version)

若返回 JSON，说明调试端口可用。

也可在命令行验证：

```bat
netstat -ano | findstr :9222
```

## 4. 未开启端口时的系统行为

- `MarsSpyTool` 会提示未检测到调试端口。  
- 系统将自动回退到 `SpyTool` 的 `UIA` 定位模式。  
- 不会启动新浏览器，也不会构建 WebAutomation 的当前页面对象树。
