# 🔐 .NET 强名称签名完整指南

## 📖 什么是强名称签名？

强名称签名（Strong Name Signing）是 .NET 程序集的一种数字签名机制，它：

- ✅ **唯一标识**程序集（名称 + 版本 + 公钥）
- ✅ **防止篡改**（任何修改都会导致签名失效）
- ✅ **防止替换**（确保加载的是原始程序集）
- ✅ **启用 GAC**（可以安装到全局程序集缓存）

---

## 🎯 为什么要使用强名称签名？

### 对于 License 管理系统的价值

| 好处 | 说明 |
|------|------|
| **防止破解** | 程序被修改后签名失效，无法运行 |
| **完整性校验** | 启动时可验证程序集是否被篡改 |
| **License 绑定** | License 可以绑定到特定的程序集版本 |
| **专业性** | 表明软件的正规性和可信度 |

## 🚀 快速开始（5分钟）

### 方法1: 使用 Visual Studio（最简单）

#### 步骤1: 生成密钥文件

1. 在 **Solution Explorer** 中右键点击项目
2. 选择 **Properties**（属性）
3. 点击左侧的 **Signing**（签名）标签
4. 勾选 **"Sign the assembly"**（为程序集签名）
5. 在下拉菜单中选择 **<New...>**

   ![Visual Studio Signing](https://docs.microsoft.com/en-us/visualstudio/ide/media/sign-assembly.png)

6. 在弹出的对话框中：
   - **Key file name**: 输入 `MarsSpyTool.snk`
   - **Protect my key file with a password**: 取消勾选（或设置密码）
   - 点击 **OK**

#### 步骤2: 编译

直接编译项目，程序集会自动使用强名称签名。

```bash
# 在 Visual Studio 中按 F6 或
msbuild MarsSpyTool.csproj /p:Configuration=Release
```

#### 步骤3: 验证签名

```bash
# 使用 sn.exe 工具验证
sn -v bin\Release\MarsSpyTool.exe

# 输出应该显示：
# MarsSpyTool.exe is valid
```

✅ **完成！** 您的程序集现在有强名称签名了。

## 🎯 与 License 系统集成

### 在代码中验证程序集签名

在 `MarsLicenseManager.cs` 或启动代码中添加：

```csharp
using System;
using System.Reflection;
using System.Security.Policy;

/// <summary>
/// 验证程序集是否有有效的强名称签名
/// </summary>
public static bool VerifyAssemblyStrongName()
{
    try
    {
        var assembly = Assembly.GetExecutingAssembly();
        
        // 获取公钥
        byte[] publicKey = assembly.GetName().GetPublicKey();
        
        // 检查是否签名
        if (publicKey == null || publicKey.Length == 0)
        {
            logger.Error("VerifyAssemblyStrongName\tAssembly is not signed with a strong name");
            return false;
        }
        
        // 获取公钥令牌
        byte[] publicKeyToken = assembly.GetName().GetPublicKeyToken();
        string token = BitConverter.ToString(publicKeyToken).Replace("-", "");
        
        logger.Info($"VerifyAssemblyStrongName\tPublic key token: {token}");
        
        // 可选：验证公钥令牌是否匹配预期值
        const string EXPECTED_TOKEN = "8F3C6A5D2E1B4C7A"; // 替换为您的实际令牌
        if (!string.Equals(token, EXPECTED_TOKEN, StringComparison.OrdinalIgnoreCase))
        {
            logger.Error($"VerifyAssemblyStrongName\tPublic key token mismatch. Expected: {EXPECTED_TOKEN}, Actual: {token}");
            return false;
        }
        
        logger.Info("VerifyAssemblyStrongName\tAssembly signature verified successfully");
        return true;
    }
    catch (Exception ex)
    {
        logger.Error(ex, $"VerifyAssemblyStrongName\tException: {ex.Message}");
        return false;
    }
}
```

### 在应用启动时验证

在 `App.xaml.cs` 的 `Application_Startup` 中：

```csharp
private void Application_Startup(object sender, StartupEventArgs e)
{
    // 验证程序集签名
    if (!VerifyAssemblyStrongName())
    {
        MessageBox.Show(
            "程序集签名验证失败。\n\n" +
            "可能的原因：\n" +

            "请从官方渠道重新下载。",
            "安全警告",
            MessageBoxButton.OK,
            MessageBoxImage.Error);
        Application.Current.Shutdown();
        return;
    }
    
    // 继续正常的 License 验证
    // ...
}
```

### 将签名信息嵌入 License

在生成 License 时，可以包含程序集的公钥令牌：

```csharp
public static string GenerateEnterpriseKeyForAssembly(
    string licensedTo,
    DateTime expirationDate,
    string assemblyPublicKeyToken)
{
    var license = new MarsLicenseInfo
    {
        // ... 其他属性
        ExtendedProperties = JsonConvert.SerializeObject(new
        {
            AssemblyPublicKeyToken = assemblyPublicKeyToken,
            AssemblyVersion = "1.0.0.0"
        })
    };
    
    return MarsLicenseManager.GenerateLicenseKey(license);
}

// 验证时检查
public bool ValidateLicenseForCurrentAssembly(MarsLicenseInfo license)
{
    if (string.IsNullOrEmpty(license.ExtendedProperties))
        return true; // 旧版本 License，不检查
    
    var props = JsonConvert.DeserializeObject<dynamic>(license.ExtendedProperties);
    string expectedToken = props.AssemblyPublicKeyToken;
    
    var assembly = Assembly.GetExecutingAssembly();
    byte[] actualToken = assembly.GetName().GetPublicKeyToken();
    string actualTokenStr = BitConverter.ToString(actualToken).Replace("-", "");
    
    return string.Equals(expectedToken, actualTokenStr, StringComparison.OrdinalIgnoreCase);
}
```

## ⚠️ 重要注意事项

### 1. 密钥文件安全

```bash
# ❌ 不要做的事：
# - 不要将 .snk 文件提交到公共 Git 仓库
# - 不要在多个产品间共享密钥
# - 不要将密钥文件放在可访问的服务器上

# ✅ 应该做的事：
# - 将 .snk 文件添加到 .gitignore
# - 使用密钥容器或 Azure Key Vault
# - 限制只有授权的构建机器才能访问
```

### 2. .gitignore 配置

在项目根目录的 `.gitignore` 中添加：

```gitignore
# 强名称密钥文件
*.snk
*.pfx

# 但如果是测试密钥，可以选择性包含
# !Test.snk
```

### 3. 引用其他强名称程序集

如果您的项目引用了强名称程序集，您的程序集也必须使用强名称签名。

```xml
<!-- 如果引用的程序集有强名称，需要完整的引用 -->
<Reference Include="SomeLibrary, Version=1.0.0.0, Culture=neutral, PublicKeyToken=8f3c6a5d2e1b4c7a" />
```

### 4. 版本控制

强名称签名会绑定程序集版本：

```csharp
// 在 AssemblyInfo.cs 中
[assembly: AssemblyVersion("1.0.0.0")]
[assembly: AssemblyFileVersion("1.0.0.0")]

// 版本变化会导致签名不同
// 1.0.0.0 → 1.0.0.1 = 不同的强名称
```

## 🔧 高级配置

### 1. 延迟签名（Delay Signing）

用于开发阶段，只使用公钥签名，稍后再用私钥完成签名：

```xml
<PropertyGroup>
  <SignAssembly>true</SignAssembly>
  <DelaySign>true</DelaySign>
  <AssemblyOriginatorKeyFile>PublicKey.snk</AssemblyOriginatorKeyFile>
</PropertyGroup>
```

```bash
# 提取公钥
sn -p MarsSpyTool.snk PublicKey.snk

# 跳过验证（开发时）
sn -Vr MarsSpyTool.exe

# 稍后完成签名（发布时）
sn -R MarsSpyTool.exe MarsSpyTool.snk
```

### 2. 使用 Azure Key Vault（云端密钥管理）

```bash
# 安装 Azure CLI
az login

# 创建密钥保管库
az keyvault create --name MarsKeyVault --resource-group MarsRG

# 上传密钥
az keyvault secret set --vault-name MarsKeyVault --name SnkKey --file MarsSpyTool.snk

# 在构建管道中获取
az keyvault secret download --vault-name MarsKeyVault --name SnkKey --file temp.snk
```

### 3. 条件编译签名

只在 Release 配置中签名：

```xml
<PropertyGroup Condition=" '$(Configuration)' == 'Release' ">
  <SignAssembly>true</SignAssembly>
  <AssemblyOriginatorKeyFile>MarsSpyTool.snk</AssemblyOriginatorKeyFile>
</PropertyGroup>

<PropertyGroup Condition=" '$(Configuration)' == 'Debug' ">
  <SignAssembly>false</SignAssembly>
</PropertyGroup>
```

## 📊 签名状态检查工具

### PowerShell 脚本

创建 `check_assembly_signature.ps1`：

```powershell
param(
    [Parameter(Mandatory=$true)]
    [string]$AssemblyPath
)

Write-Host "检查程序集签名: $AssemblyPath" -ForegroundColor Cyan
Write-Host ""

if (-not (Test-Path $AssemblyPath)) {
    Write-Host "错误: 文件不存在" -ForegroundColor Red
    exit 1
}

# 使用 sn.exe 验证
$snPath = "C:\Program Files (x86)\Microsoft SDKs\Windows\v10.0A\bin\NETFX 4.8 Tools\sn.exe"

if (Test-Path $snPath) {
    Write-Host "1. 验证强名称签名..." -ForegroundColor Yellow
    & $snPath -v $AssemblyPath
    Write-Host ""
    
    Write-Host "2. 查看公钥令牌..." -ForegroundColor Yellow
    & $snPath -T $AssemblyPath
    Write-Host ""
} else {
    Write-Host "未找到 sn.exe，请安装 .NET Framework SDK" -ForegroundColor Yellow
}

# 使用 .NET 反射检查
Write-Host "3. 使用 .NET 反射检查..." -ForegroundColor Yellow

Add-Type -TypeDefinition @"
using System;
using System.Reflection;

public class AssemblyChecker
{
    public static void CheckAssembly(string path)
    {
        try
        {
            Assembly asm = Assembly.LoadFile(path);
            byte[] publicKey = asm.GetName().GetPublicKey();
            byte[] publicKeyToken = asm.GetName().GetPublicKeyToken();
            
            if (publicKey != null && publicKey.Length > 0)
            {
                Console.WriteLine("✓ 程序集已签名");
                Console.WriteLine("  公钥长度: {0} 字节", publicKey.Length);
                Console.WriteLine("  公钥令牌: {0}", BitConverter.ToString(publicKeyToken).Replace("-", ""));
                Console.WriteLine("  版本: {0}", asm.GetName().Version);
            }
            else
            {
                Console.WriteLine("✗ 程序集未签名");
            }
        }
        catch (Exception ex)
        {
            Console.WriteLine("错误: {0}", ex.Message);
        }
    }
}
"@

[AssemblyChecker]::CheckAssembly((Resolve-Path $AssemblyPath).Path)

Write-Host ""
Write-Host "检查完成" -ForegroundColor Green
```


## 🎯 最佳实践总结

### ✅ 推荐做法

1. **生产环境必须签名**
   ```xml
   <PropertyGroup Condition=" '$(Configuration)' == 'Release' ">
     <SignAssembly>true</SignAssembly>
   </PropertyGroup>
   ```

2. **密钥文件安全存储**
   - 使用密钥容器或 Azure Key Vault
   - 不要提交到版本控制系统
   - 限制访问权限

3. **启动时验证签名**
   ```csharp
   if (!VerifyAssemblyStrongName())
   {
       // 拒绝运行
   }
   ```

4. **License 绑定签名**
   - 在 License 中包含公钥令牌
   - 验证时检查匹配

5. **自动化构建**
   - 在 CI/CD 中自动签名
   - 验证签名后才发布

### ❌ 避免的做法

1. ❌ 在公共仓库中提交 .snk 文件
2. ❌ 多个产品使用同一个密钥
3. ❌ 在 Debug 和 Release 使用不同的签名策略
4. ❌ 忽略签名验证失败
5. ❌ 明文存储密码保护的密钥密码

## 📞 故障排除

### 问题1: "Failed to sign bin\Release\MarsSpyTool.exe. File not found."

**原因**: 找不到密钥文件

**解决**:
```bash
# 确认密钥文件存在
dir MarsSpyTool.snk

# 检查项目文件中的路径
```

### 问题2: "Assembly generation failed -- Referenced assembly does not have a strong name"

**原因**: 引用了没有强名称的程序集

**解决**:
- 为引用的程序集也添加强名称签名
- 或使用 `InternalsVisibleTo` 属性

### 问题3: 签名后程序无法调试

**原因**: Debug 配置也启用了签名

**解决**:
```xml
<!-- 只在 Release 配置中签名 -->
<PropertyGroup Condition=" '$(Configuration)' == 'Release' ">
  <SignAssembly>true</SignAssembly>
</PropertyGroup>
```
