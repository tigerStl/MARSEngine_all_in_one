# 🛡️ .NET 防止反编译完整指南

## 📖 问题背景

.NET 程序编译后是 **IL 中间语言**（MSIL），而非机器码，这意味着：

❌ **容易被反编译**  
- ILSpy、dnSpy、.NET Reflector 等工具可以轻松还原源代码
- 90% 的代码逻辑可以被还原
- License 验证逻辑、加密密钥等敏感信息会暴露

✅ **本指南提供的解决方案**  
- 代码混淆（推荐）
- 代码加密
- 虚拟机保护
- Native AOT 编译
- 多层防护策略

## 🔐 方案2: 运行时保护

### 2.1 反调试检测

在 `App.xaml.cs` 中添加：

```csharp
using System.Diagnostics;
using System.Runtime.InteropServices;
using System.Threading;

public class AntiDebugger
{
    [DllImport("kernel32.dll")]
    private static extern bool IsDebuggerPresent();
    
    [DllImport("kernel32.dll")]
    private static extern bool CheckRemoteDebuggerPresent(IntPtr hProcess, ref bool isDebuggerPresent);
    
    private static bool debuggerDetected = false;
    private static Timer checkTimer;
    
    /// <summary>
    /// 启动反调试检测
    /// </summary>
    public static void StartAntiDebug()
    {
        // 检查是否有调试器附加
        if (Debugger.IsAttached || IsDebuggerPresent())
        {
            debuggerDetected = true;
            HandleDebuggerDetected();
            return;
        }
        
        // 定期检查（每秒）
        checkTimer = new Timer(CheckDebugger, null, 0, 1000);
    }
    
    private static void CheckDebugger(object state)
    {
        bool isDebuggerPresent = false;
        
        // 方法1: Debugger.IsAttached
        if (Debugger.IsAttached)
        {
            debuggerDetected = true;
        }
        
        // 方法2: IsDebuggerPresent
        if (IsDebuggerPresent())
        {
            debuggerDetected = true;
        }
        
        // 方法3: CheckRemoteDebuggerPresent
        CheckRemoteDebuggerPresent(Process.GetCurrentProcess().Handle, ref isDebuggerPresent);
        if (isDebuggerPresent)
        {
            debuggerDetected = true;
        }
        
        if (debuggerDetected)
        {
            checkTimer?.Dispose();
            HandleDebuggerDetected();
        }
    }
    
    private static void HandleDebuggerDetected()
    {
        // 方式1: 直接退出
        Environment.Exit(1);
        
        // 方式2: 误导性行为（更隐蔽）
        // Thread.Sleep(Timeout.Infinite);
        
        // 方式3: 显示误导信息
        // MessageBox.Show("License 验证失败", "错误");
        // Environment.Exit(0);
    }
}

// 在 Application_Startup 中调用
private void Application_Startup(object sender, StartupEventArgs e)
{
    // 启动反调试保护
    AntiDebugger.StartAntiDebug();
    
    // 其他启动代码...
}
```

### 2.2 完整性校验

```csharp
using System.IO;
using System.Security.Cryptography;

public class IntegrityChecker
{
    // 在发布时计算并硬编码这个值
    private const string EXPECTED_HASH = "YOUR_ASSEMBLY_HASH_HERE";
    
    /// <summary>
    /// 验证程序集是否被修改
    /// </summary>
    public static bool VerifyIntegrity()
    {
        try
        {
            string exePath = Assembly.GetExecutingAssembly().Location;
            
            using (var sha256 = SHA256.Create())
            {
                using (var stream = File.OpenRead(exePath))
                {
                    byte[] hash = sha256.ComputeHash(stream);
                    string currentHash = BitConverter.ToString(hash).Replace("-", "");
                    
                    // 对比哈希值
                    if (!string.Equals(currentHash, EXPECTED_HASH, StringComparison.OrdinalIgnoreCase))
                    {
                        logger.Error($"Integrity check failed. Expected: {EXPECTED_HASH}, Current: {currentHash}");
                        return false;
                    }
                }
            }
            
            return true;
        }
        catch (Exception ex)
        {
            logger.Error(ex, "Integrity check exception");
            return false;
        }
    }
}

// 在启动时验证
private void Application_Startup(object sender, StartupEventArgs e)
{
    if (!IntegrityChecker.VerifyIntegrity())
    {
        MessageBox.Show(
            "程序文件已被修改，无法运行。\n请从官方渠道重新下载。",
            "完整性验证失败",
            MessageBoxButton.OK,
            MessageBoxImage.Error);
        Application.Current.Shutdown();
        return;
    }
    
    // 继续启动...
}
```

## ⚠️ 重要注意事项

### 1. 混淆可能导致的问题

```csharp
// ❌ 这些情况可能出错：
// - 反射调用
Type.GetType("MarsSpyTool.MarsLicenseManager"); // 类名被混淆后会找不到

// - 序列化/反序列化
JsonConvert.SerializeObject(license); // 属性名被混淆

// - XAML 绑定
// {Binding LicensedTo} // 属性名被混淆
```

**解决方案**：在混淆配置中排除这些类/属性

```xml
<rule pattern="true" preset="maximum">
  <!-- 排除需要反射的类 -->
  <module path="MarsSpyTool.exe">
    <type fullname="MarsSpyTool.Utility.License.MarsLicenseInfo">
      <protection id="rename" action="remove" />
    </type>
  </module>
</rule>
```

### 2. 调试混淆后的程序

```xml
<!-- 在 confuser.crproj 中保留符号 -->
<protection id="rename">
  <argument name="renPdb" value="true" />
</protection>
```
