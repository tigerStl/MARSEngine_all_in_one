# 🛡️ 防止 ILSpy 反编译 - 5分钟快速指南

## 📖 问题

ILSpy、dnSpy、.NET Reflector 等工具可以轻松反编译 .NET 程序，暴露您的代码逻辑和 License 验证机制。

---

## ✅ 最简单有效的解决方案（3步，10分钟）

### 步骤1: 代码混淆 - ConfuserEx（免费）⭐⭐⭐⭐⭐

#### 1.1 下载 ConfuserEx

```powershell
# 从 GitHub 下载
Invoke-WebRequest -Uri "https://github.com/yck1509/ConfuserEx/releases/download/v1.6.0/ConfuserEx-CLI.zip" -OutFile "ConfuserEx.zip"

# 解压到项目
Expand-Archive ConfuserEx.zip -DestinationPath "Tools\ConfuserEx"
```

或者手动下载：https://github.com/yck1509/ConfuserEx/releases

#### 1.2 创建配置文件

在项目根目录创建 `confuser.crproj`：

```xml
<project baseDir="bin\Release" outputDir="bin\Release_Obfuscated" xmlns="http://confuser.codeplex.com">
  <module path="MarsSpyTool.exe">
    <rule pattern="true" preset="maximum" inherit="false">
      <protection id="anti debug" />
      <protection id="anti dump" />
      <protection id="anti ildasm" />
      <protection id="anti tamper" />
      <protection id="constants" />
      <protection id="ctrl flow" />
      <protection id="invalid metadata" />
      <protection id="ref proxy" />
      <protection id="rename">
        <argument name="mode" value="decodable" />
      </protection>
      <protection id="resources" />
    </rule>
  </module>
</project>
```

#### 1.3 运行混淆

```powershell
# 1. 先正常编译
msbuild MarsSpyTool.csproj /p:Configuration=Release

# 2. 运行混淆
.\Tools\ConfuserEx\Confuser.CLI.exe confuser.crproj

# 3. 混淆后的文件在 bin\Release_Obfuscated\
```

### 步骤2: 添加反调试保护（5分钟）

在 `App.xaml.cs` 的 `Application_Startup` 开头添加：

```csharp
using MarsSpyTool.Utility.License;

private void Application_Startup(object sender, StartupEventArgs e)
{
    // 启动反调试保护
    AntiDebugProtection.StartProtection();
    
    // 验证程序集完整性
    if (!AntiDebugProtection.VerifyIntegrity())
    {
        MessageBox.Show("程序文件已被修改", "安全警告");
        Application.Current.Shutdown();
        return;
    }
    
    // 原有的启动代码...
}
```

### 步骤3: 强名称签名（2分钟）

```bash
# 生成密钥
sn -k MarsSpyTool.snk
```

编辑 `MarsSpyTool.csproj`：
```xml
<PropertyGroup>
  <SignAssembly>true</SignAssembly>
  <AssemblyOriginatorKeyFile>MarsSpyTool.snk</AssemblyOriginatorKeyFile>
</PropertyGroup>
```

## ⚠️ 注意事项

### 1. 排除某些类（如果混淆后出错）

如果某些类需要反射或序列化，需要排除混淆：

```xml
<rule pattern="true" preset="maximum">
  <!-- 排除 License 信息类（用于 JSON 序列化）-->
  <module path="MarsSpyTool.exe">
    <type fullname="MarsSpyTool.Utility.License.MarsLicenseInfo">
      <protection id="rename" action="remove" />
    </type>
  </module>
</rule>
```

### 2. .gitignore 配置

```gitignore
# 不要提交密钥文件
*.snk

# 不要提交混淆工具
Tools/ConfuserEx/
```

### 3. 保留原始版本用于调试

```
bin/Release/              # 原始版本（调试用）
bin/Release_Obfuscated/   # 混淆版本（发布用）
```
