# 🔐 将 License 信息嵌入编译文件 - 完整指南

## 📖 概述

将 License 信息嵌入到编译后的可执行文件中，可以实现：
- ✅ **预授权分发**：无需用户手动激活
- ✅ **OEM 定制**：为特定客户编译专属版本
- ✅ **防止篡改**：License 与程序集绑定
- ✅ **简化部署**：无需管理外部 License 文件

---

## 🎯 四种实现方案

### 方案对比

| 方案 | 安全性 | 灵活性 | 实现难度 | 推荐场景 |
|------|--------|--------|----------|----------|
| **方案1: 嵌入资源** | ⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐ | 标准预授权 |
| **方案2: Assembly 属性** | ⭐⭐ | ⭐⭐⭐ | ⭐ | 简单场景 |
| **方案3: 编译时常量** | ⭐⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐ | OEM 定制 |
| **方案4: 混合模式** | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | 企业级部署 |

## 📦 方案1: 嵌入资源（推荐）

### 步骤 1：生成 License 文件

```csharp
// 使用生成器创建 License
string licenseKey = LicenseKeyGenerator.GenerateEnterpriseKey(
    "ABC公司", 
    DateTime.Now.AddYears(1),
    maxConcurrentUsers: 50,
    maxActivations: 1);

// 保存为加密的 License 文件
MarsLicenseManager manager = MarsLicenseManager.Instance;
manager.ActivateLicense(licenseKey, ref errorMessage);

// 此时会生成 mars.lic 文件
// 将此文件重命名为 embedded_license.lic
```

### 步骤 2：添加到项目资源

在 Visual Studio 中：

1. 创建 `Resources` 文件夹（如果不存在）
2. 复制 `embedded_license.lic` 到 `Resources` 文件夹
3. 在 Solution Explorer 中选择该文件
4. 设置属性：
   - **Build Action**: `Embedded Resource`
   - **Copy to Output Directory**: `Do not copy`

或者手动编辑 `.csproj` 文件：

```xml
<ItemGroup>
  <EmbeddedResource Include="Resources\embedded_license.lic" />
</ItemGroup>
```

### 步骤 3：修改代码加载嵌入的 License

在 `MarsLicenseManager.cs` 的 `LoadLicense()` 方法中添加：

```csharp
private void LoadLicense()
{
    logger.Info("LoadLicense\tBegin");
    try
    {
        // 优先尝试从嵌入资源加载
        var embeddedLicense = EmbeddedLicenseManager.LoadFromEmbeddedResource(
            "MarsSpyTool.Resources.embedded_license.lic");
        
        if (embeddedLicense != null && embeddedLicense.IsValid())
        {
            logger.Info("LoadLicense\tLoaded from embedded resource");
            _currentLicense = embeddedLicense;
            
            // 可选：将嵌入的 License 保存到本地文件
            // 这样即使嵌入的 License 过期，用户还可以手动激活新的
            if (!File.Exists(_licenseFilePath))
            {
                SaveLicense(embeddedLicense);
            }
            return;
        }

        // 如果没有嵌入的 License，尝试从文件加载
        if (!File.Exists(_licenseFilePath))
        {
            logger.Warn($"LoadLicense\tLicense file not found: {_licenseFilePath}");
            _currentLicense = CreateTrialLicense();
            SaveLicense(_currentLicense);
            return;
        }

        // 原有的文件加载逻辑...
    }
    catch (Exception ex)
    {
        logger.Error(ex, $"LoadLicense\tException: {ex.Message}");
        _currentLicense = CreateTrialLicense();
    }
    finally
    {
        logger.Info("LoadLicense\tEnd");
    }
}
```

### 步骤 4：编译和发布

```bash
# 正常编译项目
msbuild MarsSpyTool.csproj /p:Configuration=Release

# License 会被编译到 exe 文件中
# 用户无需手动激活即可使用
```

## 🏷️ 方案2: Assembly 属性

### 步骤 1：在 AssemblyInfo.cs 中添加属性

编辑 `Properties/AssemblyInfo.cs`，添加：

```csharp
using MarsSpyTool.Utility.License;

// 在文件末尾添加
[assembly: EmbeddedLicense("YOUR_BASE64_ENCODED_LICENSE_KEY_HERE")]
```

### 步骤 2：生成 License Key

```csharp
// 使用生成器
string licenseKey = LicenseKeyGenerator.GenerateEnterpriseKey(
    "XYZ公司", DateTime.Now.AddYears(1));

Console.WriteLine($"License Key:\n{licenseKey}");
// 复制输出的 Key 到 AssemblyInfo.cs
```

### 步骤 3：加载 License

```csharp
private void LoadLicense()
{
    // 尝试从程序集属性加载
    var embeddedLicense = EmbeddedLicenseManager.LoadFromAssemblyAttribute();
    if (embeddedLicense != null && embeddedLicense.IsValid())
    {
        _currentLicense = embeddedLicense;
        return;
    }
    
    // 否则从文件加载...
}
```

### 优缺点

✅ **优点**：
- 实现简单
- 无需额外文件

❌ **缺点**：
- License Key 可通过反编译看到
- 需要重新编译才能更新 License

## 🔧 方案3: 编译时常量（最安全）

### 步骤 1：创建 T4 模板

创建 `Properties/LicenseConstants.tt` 文件：

```t4
<#@ template debug="false" hostspecific="true" language="C#" #>
<#@ assembly name="System.Core" #>
<#@ import namespace="System.IO" #>
<#@ output extension=".cs" #>
<#
    // 从配置文件读取 License 信息
    string configPath = this.Host.ResolvePath("license_build_config.json");
    string json = File.ReadAllText(configPath);
    
    // 这里简化处理，实际应该解析 JSON
    string licensedTo = "客户公司名";
    int licenseType = 3; // Enterprise
    long expirationTicks = 638000000000000000;
    int features = 255; // All features
#>
// <auto-generated>
// 此文件由 T4 模板自动生成，请勿手动修改
// 生成时间: <#= DateTime.Now.ToString("yyyy-MM-dd HH:mm:ss") #>
// </auto-generated>

#define EMBEDDED_LICENSE

namespace MarsSpyTool.Utility.License
{
    internal static class CompiledLicenseConstants
    {
        internal const string EMBEDDED_LICENSE_KEY = "<#= Guid.NewGuid().ToString("N").ToUpper() #>";
        internal const string EMBEDDED_LICENSE_TO = "<#= licensedTo #>";
        internal const int EMBEDDED_LICENSE_TYPE = <#= licenseType #>;
        internal const long EMBEDDED_EXPIRATION_TICKS = <#= expirationTicks #>L;
        internal const int EMBEDDED_FEATURES = <#= features #>;
        internal const string EMBEDDED_SUPPORTED_VERSIONS = "1.0,2.0,3.0";
    }
}
```

### 步骤 2：创建配置文件

创建 `Properties/license_build_config.json`：

```json
{
  "licensedTo": "客户公司名称",
  "licenseType": "Enterprise",
  "expirationDate": "2026-12-31",
  "features": [
    "BasicObjectSpy",
    "SingleObjectMode",
    "AutoGenerateTestCase",
    "RecordReplay",
    "MultiDatabase",
    "AdvancedObjectRecognition",
    "BatchOperation",
    "CloudSync"
  ],
  "maxConcurrentUsers": 50,
  "maxActivations": 1,
  "supportedVersions": ["1.0", "2.0", "3.0"]
}
```

### 步骤 3：在编译前运行 T4 模板

在项目文件中添加：

```xml
<PropertyGroup>
  <PreBuildEvent>
    REM 运行 T4 模板生成 License 常量
    TextTransform.exe "$(ProjectDir)Properties\LicenseConstants.tt" -out "$(ProjectDir)Properties\LicenseConstants.cs"
  </PreBuildEvent>
</PropertyGroup>
```

### 步骤 4：使用常量

```csharp
#if EMBEDDED_LICENSE
var license = new MarsLicenseInfo
{
    LicenseKey = CompiledLicenseConstants.EMBEDDED_LICENSE_KEY,
    LicensedTo = CompiledLicenseConstants.EMBEDDED_LICENSE_TO,
    Type = (LicenseType)CompiledLicenseConstants.EMBEDDED_LICENSE_TYPE,
    // ... 其他属性
};
#endif
```

### 优缺点

✅ **优点**：
- 最安全，常量在编译时被内联
- 反编译也看不到完整的 License 结构
- 可以通过构建参数定制

❌ **缺点**：
- 实现复杂
- 每个客户需要单独编译
- 不够灵活

## 🌟 方案4: 混合模式（推荐企业级）

### 架构设计

```
优先级顺序：
1. 编译时常量（最安全，用于 OEM）
2. Assembly 属性（中等安全，用于预授权）
3. 嵌入资源（灵活，用于标准分发）
4. 外部文件（最灵活，用于手动激活）
```

### 实现代码

```csharp
public class MarsLicenseManager
{
    private void LoadLicense()
    {
        logger.Info("LoadLicense\tBegin - Trying multiple sources");
        
        // 使用混合加载策略
        _currentLicense = EmbeddedLicenseManager.LoadLicenseWithFallback();
        
        if (_currentLicense == null || !_currentLicense.IsValid())
        {
            logger.Warn("LoadLicense\tNo valid license found, creating trial");
            _currentLicense = CreateTrialLicense();
            SaveLicense(_currentLicense);
        }
        else
        {
            logger.Info($"LoadLicense\tSuccess|Type: {_currentLicense.Type}");
        }
    }
}
```

## 🛠️ 自动化构建脚本

### PowerShell 脚本示例

创建 `build_with_license.ps1`：

```powershell
param(
    [string]$CustomerName,
    [string]$LicenseType = "Enterprise",
    [int]$Years = 1,
    [string]$OutputPath = ".\bin\Release"
)

Write-Host "========================================" -ForegroundColor Cyan
Write-Host "  Building MARS with Embedded License" -ForegroundColor Cyan
Write-Host "========================================" -ForegroundColor Cyan
Write-Host ""

# 1. 生成 License Key
Write-Host "Generating license for: $CustomerName" -ForegroundColor Yellow

# 调用 C# 生成器（这里假设有一个 CLI 工具）
$licenseKey = & ".\Tools\LicenseGenerator.exe" `
    --customer "$CustomerName" `
    --type $LicenseType `
    --years $Years

Write-Host "License Key generated" -ForegroundColor Green

# 2. 创建 License 文件
Write-Host "Creating license file..." -ForegroundColor Yellow
# 将 License 激活并导出
& ".\Tools\LicenseExporter.exe" --key $licenseKey --output ".\Resources\embedded_license.lic"

# 3. 更新 AssemblyInfo
Write-Host "Updating AssemblyInfo..." -ForegroundColor Yellow
$assemblyInfo = Get-Content ".\Properties\AssemblyInfo.cs"
$assemblyInfo = $assemblyInfo -replace '\[assembly: EmbeddedLicense\(".*"\)\]', "[assembly: EmbeddedLicense(`"$licenseKey`")]"
Set-Content ".\Properties\AssemblyInfo.cs" $assemblyInfo

# 4. 编译项目
Write-Host "Building project..." -ForegroundColor Yellow
msbuild MarsSpyTool.csproj /p:Configuration=Release /p:Platform=AnyCPU /v:minimal

# 5. 验证编译结果
if ($LASTEXITCODE -eq 0) {
    Write-Host ""
    Write-Host "========================================" -ForegroundColor Green
    Write-Host "  Build Successful!" -ForegroundColor Green
    Write-Host "========================================" -ForegroundColor Green
    Write-Host ""
    Write-Host "Customer: $CustomerName" -ForegroundColor Cyan
    Write-Host "License Type: $LicenseType" -ForegroundColor Cyan
    Write-Host "Output: $OutputPath\MarsSpyTool.exe" -ForegroundColor Cyan
    
    # 6. 创建发布包
    $packageName = "MarsSpyTool_${CustomerName}_${LicenseType}_$(Get-Date -Format 'yyyyMMdd').zip"
    Compress-Archive -Path "$OutputPath\*" -DestinationPath ".\Releases\$packageName" -Force
    
    Write-Host ""
    Write-Host "Package created: .\Releases\$packageName" -ForegroundColor Green
} else {
    Write-Host ""
    Write-Host "Build failed!" -ForegroundColor Red
    exit 1
}
```

### 使用方法

```powershell
# 为客户 ABC 公司构建企业版
.\build_with_license.ps1 -CustomerName "ABC公司" -LicenseType "Enterprise" -Years 1

# 批量构建
$customers = @("公司A", "公司B", "公司C")
foreach ($customer in $customers) {
    .\build_with_license.ps1 -CustomerName $customer -LicenseType "Professional"
}
```

## 🔐 安全增强建议

### 1. 代码混淆

使用混淆工具保护嵌入的 License：

```xml
<!-- 在 .csproj 中添加 -->
<PropertyGroup>
  <PostBuildEvent>
    REM 使用 ConfuserEx 混淆
    "$(SolutionDir)Tools\ConfuserEx.exe" -n "$(TargetPath)"
  </PostBuildEvent>
</PropertyGroup>
```

### 2. 强名称签名

```bash
# 生成强名称密钥
sn -k MarsSpyTool.snk

# 在项目属性中启用强名称签名
```

在 `.csproj` 中：

```xml
<PropertyGroup>
  <SignAssembly>true</SignAssembly>
  <AssemblyOriginatorKeyFile>MarsSpyTool.snk</AssemblyOriginatorKeyFile>
</PropertyGroup>
```

### 3. 完整性校验

在启动时验证程序集：

```csharp
private bool VerifyAssemblyIntegrity()
{
    var assembly = Assembly.GetExecutingAssembly();
    
    // 检查强名称签名
    byte[] publicKey = assembly.GetName().GetPublicKey();
    if (publicKey == null || publicKey.Length == 0)
    {
        logger.Error("Assembly not signed!");
        return false;
    }
    
    // 检查文件哈希（可选）
    // ...
    
    return true;
}
```

## 📊 方案选择指南

### 场景1: 大规模预授权分发
**推荐**：方案1（嵌入资源）
- 编译一次，分发给多个客户
- 容易更新（只需替换资源文件）

### 场景2: OEM 定制版本
**推荐**：方案3（编译时常量）
- 每个客户单独编译
- 最高安全性

### 场景3: 既有预授权又有手动激活
**推荐**：方案4（混合模式）
- 预装客户自动激活
- 其他客户手动激活

### 场景4: 简单的版本标识
**推荐**：方案2（Assembly 属性）
- 只需要标识版本信息
- 不需要高安全性
