MARS Message Agent - Sample Invoke & ShakeHand

本页面通过 ActiveX 调用 COM 组件并连接 WebSocket 发送握手包。需在支持 ActiveX 的环境（如 IE）中运行，且已注册 COM。

在 Edge 中如何创建 COM Object

Edge 默认（Chromium 模式）不支持 ActiveXObject，无法在网页里创建 COM 对象。必须使用 Edge 的 IE 模式，代码与 IE 相同：new ActiveXObject("MARSMessageAgent.Agent")。

操作步骤：

  1. 打开 Edge → 右上角 … → 设置。
  2. 左侧选 默认浏览器。
  3. 将「允许在 Internet Explorer 模式下重新加载站点」设为 允许。
  4. 用 Edge 打开本页面（sampleInvoke.html）。
  5. 在地址栏左侧或右侧点击 在 Internet Explorer 模式下重新加载（或 … 菜单里选该项）。
  6. 页面刷新后即运行在 IE 引擎下，此时可点击「1. 创建并激活 Agent」创建 COM 对象。

若希望每次打开该站点自动用 IE 模式：设置 → 默认浏览器 → 「Internet Explorer 模式页面」中添加本页的站点（例如 file:// 或你的服务器域名）。

当前浏览器不支持 ActiveX

ActiveXObject 仅在 Internet Explorer 或 Microsoft Edge 的 IE 模式 下可用。Chrome、Firefox、Safari 等无法调用 COM。

请改用以下方式之一打开本页面：

  • Internet Explorer 11：直接双击本 .html 或用 IE 打开。
  • Microsoft Edge：按上方「在 Edge 中如何创建 COM Object」的步骤切换到 IE 模式后刷新本页。
  • 非 IE 模式（Chrome / Edge 普通模式）：见下方「非 IE 模式」说明，先运行 exe 再点击获取端口并发送 ShakeHand。
非 IE 模式（Chrome / Edge 普通模式 / Firefox）

无法通过网页创建 COM 对象，但可仅用 WebSocket 与已运行的 Agent 通信。

步骤：

  1. 先运行 MARSMessageAgent.exe（双击或快捷方式），确保托盘出现且无报错。
  2. 点击下方「获取端口并发送 ShakeHand」：页面会请求 http://127.0.0.1:10005/ 获取 WebSocket 端口，再连接并发送握手包。
  3. 若获取失败，可手动填写端口（如 10010）后点击「按端口连接并发送 ShakeHand」。
