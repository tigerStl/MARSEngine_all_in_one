# 功能说明记录

## 2026-02-18 - Java JTable 录制增强

### 目标
增强 Java JTable 录制逻辑，支持右键/弹出菜单/更新提交的高质量步骤生成，并在高亮时尽量定位到具体单元格。

### 功能点
1. 右击 JTable 单元格
   - 产生步骤：
     - keyword: `SearchAndClick`
     - object: JTable
     - parameter: `RightClick;columnName` 或 `RightClick;columnName;[conditonColumn1;conditonColumn2...]`
     - data: `cellValue` 或 `[conditonColumnValue1;conditonColumnValue2...]cellValue`

2. 右击后弹出菜单选择
   - 产生步骤：
     - keyword: `SelectPopupMenu`
     - object: 菜单项（可为空/可用菜单信息）
     - parameter: 空
     - data: 菜单项文本

3. 仅左击且无键盘操作
   - 不记录步骤。

4. 左击/编辑/切换单元格/Enter/Tab
   - 产生步骤：
     - keyword: `SearchAndUpdate`
     - object: JTable
     - parameter: `targetColumnName` 或 `targetColumnName;[conditonColumn1;conditonColumn2...]`
     - data: `sourceData:TargetData` 或 `[conditonColumnValue1;conditonColumnValue2]sourceData:TargetData`

5. 高亮
   - 在步骤元数据中附加 `cellBounds`（屏幕坐标），用于尽量高亮到具体单元格。

### 条件列配置
支持通过 JTable 的 clientProperty 指定条件列组合：
- `mars.keyColumns` 或 `mars.conditionColumns`
- 支持 String（用 `;` 或 `,` 分隔）、String[]、List。

### 备注
- JTable 内部编辑不会触发 `FillEdit`，统一由 `SearchAndUpdate` 记录。
- 右键触发 `SearchAndClick`，其后菜单项选择触发 `SelectPopupMenu`。
