# MARS.WebAutomation 需求说明

## 1. 工程与交付形态

- 在 **MARS.WebAutomation** 工程下建立基于 **.NET Framework**（目标框架 **v4.7.2**）的 **类库（DLL）** 输出；工程文件采用 **SDK 风格**（`TargetFramework=net472`），以便 NuGet（Playwright 等）引用能正确参与编译（与部分旧式 csproj 的 PackageReference 行为一致）。
- 对外提供 API（例如启动工作台窗体），由宿主进程加载后弹出 WinForms 界面。
- 建立 **doc** 目录，维护 **需求.md**（本文）、**详细设计.md**、**状态追踪.md**（WBS 与进度）。
- 运行数据落盘路径约定：`data\[WebDomain]_key\test_[Url规范化].json`。

## 2. 工作台 UI

### 2.1 主窗体

- 主界面为 **Form**，包含 **MenuStrip** 与 **ToolStrip（Toolbar）**。
- 工作区为大型 **TabControl**，分四个页签（见 2.3）。

### 2.2 Toolbar 功能分区（以 `ToolStripSeparator` 分隔小区）

| 分区 | 按钮/图标 | 行为概要 |
|------|-------------|----------|
| 目标与对象 | Target | 进入/退出对象定位模式，从页面选取 DOM 节点并刷新对象树与详情 |
| 录制回放 | Recorder | 开始/停止录制，将页面事件转为语义 Keyword 列表 |
| 录制回放 | Replay | 按当前语义步骤在已连接页面上回放 |
| 数据交换 | Export / Import | 导出/导入当前测试 JSON 文档 |
| 文件 | Save | 按约定路径保存当前会话数据 |

（图标当前阶段可使用文字按钮或系统内置图标，后续可替换为资源图片。）

### 2.3 Tab 页内容

1. **目标页面**  
   - 显示当前 **URL**、**导航**操作入口。  
   - **URL 解析**：Scheme、Host、Port、Path、Query 等结构化展示。

2. **界面 Object**  
   - **左右布局**：左侧 **TreeView** 展示当前页面对象层次（由页面脚本采集的简化 DOM/语义树）；右侧 **DataGridView** 展示选中节点属性：**X/Y/宽/高**、**定位方法（Playwright 推荐模式）**、**Role/Tag** 等。

3. **Record & Replay**  
   - 列表展示已录制 **语义事件**：Keyword、Locator 模式、Parameter、Data（文本、窗口标题等）。  
   - **语义 Keyword 映射**（界面事件 → 关键字），包括但不限于：  
     - `FillEdit`  
     - `SelectDropDown`  
     - `SetBox`（Checkbox / Radio）  
     - `ClickButton`（button、image、icon、a[href] 等可点击语义）  
     - 表格类（`table`、`PQ_table`、常规 JS/VUE 表格等）：`FillTable`（参数描述如何定位 Cell，如 `Column:列名:RowFilter:...`）、`SearchAndUpdate`、`SearchAndClick` 等（首版实现映射框架与扩展点，复杂表格策略可迭代）。

4. **Settings**  
   - Playwright 相关：浏览器通道、是否无头、超时、视口等。  
   - 其他系统级选项（可扩展）：数据根目录等。

## 3. Web Record & Replay 自动化

- 基于 **Microsoft.Playwright** 连接 **Chromium**（可扩展其他浏览器类型）。  
- **录制**：在页面上下文注入监听（捕获阶段），通过 **ExposeBinding** 将事件回传到宿主，再映射为语义 Keyword 与 Locator。  
- **回放**：根据保存的 Keyword + Locator + 参数执行对应 Playwright API（点击、填充、选择、勾选等）。  
- 支持从 Toolbar 启停录制与一键回放。

## 4. HTTP/XHR 采集（面向后期性能测试）

- 当录制页面存在 **GET/POST** 等 **XHR/Fetch** 请求时，抽取并保存：  
  - 方法、URL、状态码  
  - 关键 **Request Headers**、**Response Headers**（可配置是否包含 Cookie 等敏感字段的落盘策略）  
  - **Cookie** 摘要（若可得）  
- 数据写入与主测试文档同一套 JSON 模型中的 **NetworkCaptures** 段，便于后续性能/压测工具消费。

## 5. 数据存储

- 根目录：`data\`（可配置，默认相对当前工作目录或程序集目录）。  
- 子目录：`[WebDomain]_key\`，其中 `WebDomain` 为当前站点主机名规范化（非法文件名字符替换）。  
- 文件名：`test_[Url规范化].json`，Url 规范化：去协议、替换路径非法字符、控制长度。  
- 内容：页面元数据、语义步骤、网络捕获、设置快照等（详见《详细设计.md》）。

## 6. 非功能需求

- 与现有 MARS 解决方案风格一致：旧式 **csproj**、**C#**、WinForms。  
- 异常与长时间操作需有用户可见反馈（MessageBox / StatusStrip）。  
- 文档与 **README** 随迭代更新；**状态追踪.md** 中 WBS 项完成后勾选并记录日期。

## 7. 与 MarsSpyTool 联动新增需求

### 7.1 Finder 拖放到 Web 对象时的处理

- 由 `MarsSpyTool` 在 Finder 的 `mouseLeftButtonUpImp` 中识别是否为浏览器进程。  
- 若识别为 Web 浏览器，则调用 `MARS.WebAutomation` 进入 Web 工作台联动流程。

### 7.2 调试端口前置检查与回退

- `MARS.WebAutomation` 提供 CDP 调试端口可用性检查（默认检测 `9222/9223`）。  
- 当未启用调试端口时，**不再回退启动新浏览器**。  
- 需要提示用户：“未检测到调试端口，将转为 SpyTool 的 UIA 定位模式。”  
- 随后由 `MarsSpyTool` 直接回退至 `UIA` 定位（`MarsObjSpyForm.StartAccessibleModeFromXY`）。

### 7.3 MainWorkbenchForm 单例模式

- `MainWorkbenchForm` 全局保持单实例，重复调用仅激活已打开窗口。  
- 当窗口关闭时，必须将全局单例引用置空，确保后续可重新创建。

### 7.4 多语言与宿主配置

- 多语言键值由**宿主程序 app.config** 提供，不使用 WebAutomation 自身持久化设置。  
- 配置项：`UiLanguage`，默认值 `en`。  
- 支持 `zh/zh-CN` 与 `en`。  
- 宿主包括：`MarsSpyTool`、`Mars.AutoTestingDriver`（含其环境化 `app.*.config`）。

## 8. Record / Replay 工作台增强（2026-04-26 追加）

以下条目在首版需求之上增量约定；与既有章节冲突时以本节为当前迭代口径。

1. **布局**：Record / Replay 页签内步骤区为 **左右分割**（`SplitContainer`），左侧为步骤 **DataGridView**，右侧为 **WebBrowser** 流程画布；中间为可调分割条。  
2. **流程画布**：每新增一条语义步骤，右侧同步生成 **圆角卡片** 节点（工作流风格），展示关键字、逻辑对象类别、事件名、数据摘要与 Locator 片段；节点可 **拖动**，位置写入 `SemanticStepRecord.CanvasX` / `CanvasY` 并随 JSON 保存。  
3. **关键字配色**：不同 `Keyword` 使用不同卡片渐变背景（与专业工作流工具配色思路一致）。  
4. **步骤表列**：第一列为 **删除**（按钮），第二列 **序号**（`RunOrder`，随删改与上下移重算），第三列 **耗时**（相对上一步 `TimestampUtc` 的毫秒差），其后为 **Keyword**、**事件**（`SourceEvent`）、**Data**、**布局**（数值化 `BoundsDisplay`，禁止将 `BoundingRect` 对象直接 ToString）、**逻辑对象**（`LogicalKind`）、**Locator**（完整 CSS 链，优先 `id` / `data-testid` / `name` / `role+aria` / `nth-of-type` 路径）、**Parameter**。  
5. **Locator**：录制脚本生成 **尽量唯一** 的 Playwright 可用 CSS 链；对 `div`/`button` 实现的伪控件，在 `LogicalKind` 与 `Locator` 中体现可区分信息（后续可在 `Parameter` 中扩展 `property=value` 说明）。  
6. **语义录制**：不以每个 DOM `input` 事件落步；**文本类输入在 `blur` 提交** 一步（`FillEdit`），**点击仅用于聚焦文本框** 不产生步骤；`change` 仍用于 `select`、checkbox、radio 等。  
7. **逻辑对象类别**：脚本与宿主侧约定 `webEdit`、`webButton`、`webTab`、`webCheckbox`、`webRadio`、`webMenu` 等（可扩展 `webUnknown`）；依据 `tag` / `type` / `role` / `aria-haspopup` / 常见表格 class 启发式推断。  
8. **行序**：支持上下文菜单 **上移 / 下移** 调整步骤顺序；调整后 **重新编号** 并刷新画布。
