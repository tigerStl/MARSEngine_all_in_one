# MARS.WebAutomation 详细设计

## 1. 架构概览

```
+---------------------+
|  WebAutomationApp   |  对外入口（静态 ShowWorkbench 等）
+----------+----------+
           |
+----------v----------+
| MainWorkbenchForm   |  Menu + ToolStrip + TabControl
+----------+----------+
           |
     +-----+-----+------------------+
     |           |                  |
+----v----+ +----v---------+ +-------v--------+
|Playwright| |RecordingSvc | | JsonDataStore |
|HostSvc   | |ReplaySvc    | | NetworkCapture|
+----------+ +-------------+ +----------------+
```

- **PlaywrightHostService**：进程内单例式托管 `IPlaywright`、`IBrowser`、`IBrowserContext`、`IPage`；负责 Launch、Navigate、ExposeBinding、AddInitScript。  
- **RecordingService**：注册/注销页面事件绑定；维护 `BindingList<SemanticStepRecord>`。  
- **ReplayService**：遍历语义步骤调用 Playwright。  
- **NetworkCaptureService**：订阅 `Page.Request`、`Page.Response`，过滤 XHR/Fetch，归一化为 `NetworkCaptureEntry`。  
- **JsonDataStore**：序列化/反序列化 `WebTestDocument`，路径规则见需求。

## 2. 核心模型（JSON 可序列化）

### 2.1 `WebTestDocument`

| 字段 | 类型 | 说明 |
|------|------|------|
| SchemaVersion | string | 如 `1.0` |
| SavedAtUtc | string | ISO8601 |
| PageInfo | PageInfo | Url、Title、解析后的 UriParts |
| Steps | SemanticStepRecord[] | 语义步骤 |
| NetworkCaptures | NetworkCaptureEntry[] | XHR 等 |
| SettingsSnapshot | Dictionary | 可选，保存时设置副本 |

### 2.2 `PageInfo` / `UriParts`

- `OriginalUrl`、`NormalizedFileKey`  
- `Scheme`、`Host`、`Port`、`Path`、`Query`

### 2.3 `SemanticStepRecord`

| 字段 | 说明 |
|------|------|
| TimestampUtc | 事件时间 |
| SourceEvent | click / change / blur 等（见 §10.3） |
| Keyword | FillEdit / SelectDropDown / **SelectMenuItem** / SetBox / ClickButton / FillTable / … |
| Locator | Playwright 字符串（css/xpath/role 等） |
| Parameter | JSON 或键值字符串（如下拉 value、行列描述） |
| Data | 元素文本、value、窗口 title 等 |
| BoundingRect | x,y,w,h（若可得） |

（2026-04-26 起补充字段 `RunOrder`、`ElapsedMsSincePrev`、`LogicalKind`、`CanvasX`/`CanvasY`、只读 `BoundsDisplay` 等，见 **§10.2**。）

### 2.4 `NetworkCaptureEntry`

- `Id`, `Method`, `Url`, `ResourceType`  
- `RequestHeaders` / `ResponseHeaders`（字典）  
- `CookiesSummary`（字符串或键值列表，由响应头 Set-Cookie 与上下文拼接）  
- `Status`, `TimestampUtc`

### 2.5 `ObjectTreeNode`（UI 与 JSON 传输）

- `Id`, `ParentId`, `DisplayName`, `Tag`, `Role`, `LocatorHint`  
- `Bounds`（可选）  
- 树由页面 `EvaluateAsync` 返回的 JSON 反序列化填充。

## 3. 页面脚本（录制）

- 使用 `BrowserContext.AddInitScriptAsync` 在文档早期注入。  
- 使用 `ExposeBindingAsync("marsRecorderPush", ...)` 将事件异步投递到 UI 线程（`SynchronizationContext.Post`）。  
- 监听事件（capture）及语义合并策略以 **§10.3** 为准（演进自首版 `click`/`input`/`change` 描述）。  
- `describeTarget(el)`：自 `event.target` 向上生成 **稳定 Locator 建议**（优先 `data-testid`、`id`、`name`、`role+name`、文本片段、层级 css），与 Playwright 生成器策略对齐思路。  
- **Keyword 推断规则（首版）**：  
  - `select` 或 `role=combobox` → `SelectDropDown`  
  - `role=menuitem/menu/menubar` 或逻辑类别 `webMenu` → `SelectMenuItem`  
  - `input[type=checkbox|radio]` → `SetBox`  
  - `input/textarea` 且非上述 → `FillEdit`  
  - `button` / `role=button` / `a[href]` / `img` 可点击区域 → `ClickButton`  
  - `table` / `[class*=pq-grid]` 等启发式 → `FillTable` 或通用 `ClickButton`（表格单元格点击），后续细化。

## 4. 回放策略

- 按 `Keyword` 分支：  
  - `ClickButton` → `Locator.ClickAsync`  
  - `FillEdit` → `Locator.FillAsync(Data)`  
  - `SelectDropDown` → `SelectOptionAsync` 或 `Locator.SelectOptionAsync`  
  - `SelectMenuItem` →  
    - 若 `Data` 包含 `;`（如 `File;Open`），按路径逐级 `GetByRole(Menuitem, Name=segment).ClickAsync`  
    - 否则回退 `Locator.ClickAsync`  
  - `SetBox` → `SetCheckedAsync`  
  - `FillTable` / `SearchAndClick` → 解析 `Parameter` 中的行列定位子 DSL，调用对应 Locator（首版：参数化 `Locator` + `Data`）。  
- 每步可配置 **Timeout**、**Force**（来自 Settings）。

## 5. UI 线程与异步

- WinForms 上使用 `ConfigureAwait(true)` 回到 UI 线程更新控件。  
- Playwright 调用在 `async void` 事件处理器中执行，异常 `try/catch` + `MessageBox.Show`。

## 6. 路径与安全

- `PathHelper.BuildDataPath(baseRoot, uri)`：  
  - `domain = uri.Host` 替换 `\ / : * ? " < > |`  
  - `fileKey = SanitizeUrlForFileName(uri)`  
- Cookie/敏感头：Settings 中 `PersistSensitiveHeaders` 默认 `false`，仅保存 header 键名或打码（首版：完整保存但文档中提示生产关闭；实现为可配置）。

## 7. 扩展点

- `ISemanticKeywordHandler`：后续为每种 Keyword 单独插件化。  
- `ITableStrategy`：PQ/Vue/Ag-Grid 等表格识别插件。

## 8. 依赖

- `Microsoft.Playwright`  
- `Newtonsoft.Json`  

浏览器安装：首次部署执行 `pwsh bin\Debug\playwright.ps1 install` 或使用官方 CLI（见 README）。

## 9. MarsSpyTool 联动设计补充

### 9.1 单例窗体设计

- 在 `MainWorkbenchForm` 内部维护静态 `_instance` 与同步锁。  
- 提供 `GetOrCreateSingleton()` 与 `ResetSingleton(form)`。  
- `WebAutomationApp.ShowWorkbench*` 统一通过 `GetOrCreateSingleton()` 获取实例。  
- 若窗体已创建句柄，则仅执行激活（`Show/BringToFront/Activate`），不重复 `Application.Run`。  
- 在 `MainWorkbenchForm_FormClosed` 中调用 `ResetSingleton(this)`，关闭后释放全局引用。

### 9.2 调试端口检查与分流

- `WebAutomationApp.HasAnyCdpDebugPort()`：通过 `http://127.0.0.1:9222/json/version` 与 `9223` 做快速可用性探测。  
- `MarsSpyTool.WebSpyIntegration` 在调用 WebAutomation 前先检查调试端口：  
  - 可用：进入 `ShowWorkbenchForWebSpy` 正常联动。  
  - 不可用：弹多语言提示并直接调用 `MarsObjSpyForm.StartAccessibleModeFromXY` 执行 UIA 定位。

### 9.3 WebAutomation 内部无端口行为

- `MainWorkbenchForm.WebSpy.RunWebSpyIntegrationAsync` 在 CDP 连接失败后：  
  - 仅提示（多语言）；  
  - 不再 `StartAsync()` 启动新 Chromium；  
  - `Close()` 并返回。  
- 目的：避免“对象树来自新浏览器而非原页面”的误导。

### 9.4 多语言读取策略

- 文案函数统一读取：`ConfigurationManager.AppSettings["UiLanguage"]`。  
- 语言优先级：  
  - `zh*`（`zh`/`zh-CN`）→ 中文  
  - 其他或缺省 → 英文  
- 不再通过 `WorkbenchSettings/settings.json` 保存语言字段。  
- 宿主配置文件（`MarsSpyTool/App.config`、`Mars.AutoTestingDriver/App.config` 及 `app.*.config`）需包含：  
  - `<add key="UiLanguage" value="en" />`

## 10. Record / Replay UI 与语义录制（2026-04-26 追加）

### 10.1 主窗体布局

- `tabRecord`：`lblRecordHint`（`Dock.Top`）+ `SplitContainer`（`Dock.Fill`，竖直分割）。  
- `Panel1`：`gridSteps`（`Dock.Fill`）；`Panel2`：`WebBrowser`（`ObjectForScripting` = `RecordCanvasScriptHost`），`DocumentText` 由 `BuildRecordReplayCanvasHtml` 生成。  
- 首次 `tabRecord` 布局完成后按宽度约 **55%** 设定 `SplitterDistance`（仅初始化一次，避免与用户拖拽冲突）。

### 10.2 `SemanticStepRecord` 扩展字段

| 字段 | 说明 |
|------|------|
| RunOrder | 1-based 显示序号，导入/删行/移动后重算 |
| ElapsedMsSincePrev | 相对上一步 `TimestampUtc` 的毫秒间隔 |
| LogicalKind | 逻辑控件类：`webEdit` / `webButton` / `webTab` / `webCheckbox` / `webRadio` / `webMenu` / `webUnknown` |
| CanvasX, CanvasY | 可选，流程画布节点位置 |
| BoundsDisplay | `[JsonIgnore]` 只读展示 `x,y,w,h` 数值串 |
| TargetTag / TargetRole / TargetLocator / TargetXpath | 可选；**SelectTab** 时描述实际接收点击的 DOM 节点（标签、role、CSS 链、XPath）；主 `Locator` 仍指向 **tab 语义项**（如 `[role=tab]` 或 `.el-tabs__item`） |

### 10.3 `recorder.install.js`

- 监听：`click`、`change`、**`blur`**（capture）；**不再**监听 `input`（record 模式下语义合并）。  
- **record**：抑制 `click` 于文本类 `input`/`textarea`/`contenteditable`；抑制 `change` 于文本类；`blur` 仅对可提交文本控件推送，`Value` 为最终文本。  
- **pick**：仍仅 `click` 且阻止默认（拾取）。  
- **sync**：仅 `click` 同步树。  
- `buildLocator`：自目标向上拼接 CSS，遇 `id` / `data-testid` / `name` / `role+aria-label` 即截断，否则 `tag:nth-of-type(n)` 链（长度上限约 420）。  
- `inferLogicalKind`：与 C# `InferLogicalKindFallback` 同思路，随 payload 下发 `LogicalKind`。  
- **文本 Data**：`blur` 时对 `input`/`textarea`/`textbox` 等，将 **`Value` 与 `Text` 对齐**（优先 `value`，否则 `innerText`），保证宿主 `SemanticStepRecord.Data`、表格与流程图数据列一致。  
- **SelectTab（2026-04-26）**：在 **record + click** 下做 Tab 上下文语义：  
  - 向上在 **`RecorderTabContextAncestorDepth`** 层内（默认 5，宿主注入 `window.__marsRecoTabAncestorDepth`，写入 `WorkbenchSettings`，设置页可改 1–12）解析 **tab 容器**：`[role=tablist]`，或 **Element/Vue** 常见结构（`.el-tabs__header` → `.el-tabs`），或任意祖先 **class 含 `tabs`**（不区分大小写）。  
  - 若点击落在 **`[role=tabpanel]`** 或 **`.el-tabs__content`** 等内容区（且不在 header/tablist 内），**不**升格为 SelectTab，避免把表单输入误判为切 Tab。  
  - 命中容器后，将 **tab 项** 解析为向上链路上的 **`[role=tab]`**，或 **`.el-tabs__item`**，否则在容器内对 `button`/`a`/`span`/`li`/`div` 等回退为点击元素本身。  
  - 产生 payload：`RecorderKeyword=SelectTab`，`Locator` = **tab 项**的 `buildLocator`，`TabLabel` = 标签文案（优先点击目标 `innerText`，否则子 `span`，再否则 tab 项文本），并附带 `TargetTag` / `TargetRole` / `TargetLocator`（实际点击元素 CSS）/ `TargetXpath`（简化 XPath）。  
  - C# `RecordingService` 将 `Keyword` 定为 **SelectTab**，`LogicalKind=webTab`，`Data=TabLabel`；`ReplayService` 对 **SelectTab** 执行 **tab 项 Locator 的 Click**。

- **SelectMenuItem（2026-04-27）**：在 **record + click** 下做菜单语义：  
  - 若点击落在 `menuitem`（含常见 class 变体）并且该项存在子菜单（`aria-haspopup/menu` 或子 `role=menu`），该次点击视为“仅展开父菜单”，**不单独产生 step**。  
  - 若点击叶子菜单项，产生一条 `SelectMenuItem`：  
    - `Keyword = SelectMenuItem`  
    - `Locator` 指向叶子菜单项  
    - `Data` 为菜单根到叶子的文案链（如 `File;Open`）  
  - 这样像 `File -> Open` 的多级菜单默认只产生一条 step；回放时仍支持按 `Data` 逐级点击（兼容“逐级点击”执行需求）。

### 10.6 Objects 属性表与 `outerHTML`（2026-04-26）

- 对象树节点 DTO 增加 **`OuterHtml`**（页面脚本中截断至约 4000 字符）。  
- 属性 `DataGridView` 在展示某节点时，于 **最后一行** 显示 **outerHTML**，该行使用 **区别于普通行的背景色** 与自动换行高度，便于与常规属性区分。

### 10.4 画布脚本

- 卡片 `mousedown` 起拖，`mouseup` 调用 `window.external.NodeMoved(index, x, y)`。  
- 宿主 `RecordCanvasScriptHost.NodeMoved` 在 UI 线程更新对应 `SemanticStepRecord` 的 `CanvasX`/`CanvasY`。

### 10.5 WebView2 + 本地 React Flow（2026-04-26 修订）

- 右侧画布控件为 **`WebView2`**（Chromium），不再使用 IE `WebBrowser`。  
- 前端产物位于 **`{程序集目录}\script\workflow-app\dist\`**（由 Vite 构建），随工程 **CopyToOutputDirectory** 复制到输出目录；**不依赖 CDN**。  
- 通过 `CoreWebView2.SetVirtualHostNameToFolderMapping("mars.workflow", distFolder, Allow)` 映射虚拟主机，导航 `https://mars.workflow/index.html` 加载本地资源。  
- **C# → JS**：`CoreWebView2.PostWebMessageAsString(JSON)`，页面 `chrome.webview.addEventListener('message', …)` 消费（如 `setSteps` / `setZoom` / `centerView`）。  
- **JS → C#**：`chrome.webview.postMessage(JSON.stringify({ type, … }))`，宿主 `WebMessageReceived`（如 `nodeMoved` / `wheelZoom`）。  
- 若 `dist` 缺失则回退到 **内联 HTML** 画布（`BuildRecordReplayCanvasFallbackHtml`）。
