# MARS.WebAutomation 功能列表

## 1. 核心工作台

- WinForms 工作台入口：`WebAutomationApp.ShowWorkbench()`。  
- 主窗体 `MainWorkbenchForm`：Menu + Toolbar + 4 个主 Tab。  
- 窗体采用全局单例：重复调用仅激活，关闭时清空单例引用。

## 2. 页面连接与对象树

- Playwright Host 管理浏览器生命周期与页面访问。  
- 支持通过 CDP 连接已有 Chromium 浏览器（端口 9222/9223）。  
- 页面对象树采集与显示：Tree + Grid 联动展示属性。  
- URL 解析展示：Scheme/Host/Port/Path/Query。

## 3. 录制与回放

- 录制：DOM 事件采集并映射语义关键字（`FillEdit`、`ClickButton` 等）。  
- 回放：按关键字驱动 Playwright 执行动作。  
- 支持导入/导出步骤与保存 JSON 文档。

## 4. 网络采集

- 采集 XHR/Fetch 请求与响应信息。  
- 支持敏感头字段打码策略。  
- 与步骤数据统一写入 `WebTestDocument`。

## 5. 与 MarsSpyTool 集成

- Finder 拖放到 Web 目标时可联动打开 WebAutomation。  
- 若检测到调试端口：进入 Web 对象树联动流程。  
- 若未检测到调试端口：提示后回退到 SpyTool UIA 定位，不启动新浏览器。

## 6. 多语言（宿主配置）

- 提示文案从宿主 `app.config` 读取 `UiLanguage`。  
- 默认英文（`en`），支持中文（`zh`/`zh-CN`）。  
- 适用于 `MarsSpyTool` 与 `Mars.AutoTestingDriver` 宿主。

## 7. 数据与配置

- 结果数据默认存放：`data\[domain]_key\test_[url].json`。  
- Workbench 运行设置通过 `settings.json` 管理（不含语言）。  
- 语言统一由宿主 `app.config` 提供，避免 DLL 自身配置歧义。
